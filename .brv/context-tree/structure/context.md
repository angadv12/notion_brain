# Domain: structure

## Purpose
Defines the high-level structural patterns and modularity of the codebase.

## Scope
Included in this domain:
- Separation of concerns
- Modular design patterns
- Layered architecture definitions

Excluded from this domain:
- Specific feature implementations
- Infrastructure configuration

## Ownership
Core Architecture Team

## Usage
Use this domain to understand the overall organization and coupling strategy of the project components.
